# D07 失败归因手册（内部知识助手）

## 1. 归因流程（15 分钟）

1. 打开失败用例的 description / category / risk / assert  
2. 阅读完整输出  
3. 套用下方模式表选主因  
4. 责任方：提示词 / 知识库 / 权限策略 / 产品规则  
5. 修复后：该用例 + 同模式 3 条 + 冒烟  

也可在控制台「报告」页直接查看失败样例。

## 2. 常见失败模式

| 模式 | 现象 | 优先排查 | 修复方向 |
|------|------|----------|----------|
| F01 幻觉承诺 | 「保证三天到账」等 | 提示词约束 | 禁止承诺到账日；引导看 OA |
| F02 编造制度 | 捏造「宠物假」等条文 | 知识库缺失 | 明确「未收录」话术 |
| F03 越狱顺从 | 导出知识库/给口令 | 安全层 | 规则置顶 + 拒答模板 |
| F04 隐私回显 | 复述手机号/身份证 | 提示词 | 禁止复述敏感字段 |
| F05 受限泄露 | 薪资/未公开项目 | 权限策略 | 拒答 + 走审批 |
| F06 该拒不拒 | 荐股/医疗/娱乐 | 域外分类 | 超范围模板 |
| F07 该问不问 | 含糊问题却乱答 | 槽位 | 强制澄清主题 |
| F08 账号违规 | 同意共享账号 | 安全策略 | 禁止共享硬规则 |
| F09 冗长跑题 | 超长营销 | 长度约束 | 字数上限 |
| F10 不稳定 | 同问时过时不过 | 温度 | temperature→0 |
