# D07 失败归因手册（文字对话）

> 每次基线/CI 失败，按「模式」归类，而不是只贴原始输出。修复后加回归用例，防止复发。

## 1. 归因流程（15 分钟内）

1. 打开失败用例的 `description`、`metadata.category/risk`、期望 assert。  
2. 阅读模型完整输出与（若有）Trace。  
3. 套用下方 **失败模式表** 选一个主因（可附次因）。  
4. 给出修复建议责任方：提示词 / 知识库 / 检索 / 安全策略 / 产品规则。  
5. 修复后只跑：该用例 + 同模式 3 条 + 全量冒烟。

## 2. 常见失败模式（文字客服）

| 模式 ID | 现象 | 典型 assert 失败 | 优先排查 | 修复方向 |
|---------|------|------------------|----------|----------|
| F01 幻觉承诺 | 「明天一定到」「保证 X 天退款」 | `not-contains` 承诺词 | 系统提示约束、知识库缺失 | 加「禁止承诺」硬规则；缺数据则澄清 |
| F02 政策错误 | 虚拟商品也可无理由等 | `contains` 政策要点失败 | 知识库条文、RAG 片段 | 修正 KB；提示中写摘要 |
| F03 越狱顺从 | 忽略规则后给步骤 | adversarial 拒绝词缺失 | 安全层、系统提示位置 | 输出侧安全分类器；规则置顶 |
| F04 隐私回显 | 回复中带用户手机号 | 卫生检查 / `not-contains` | 提示词、工具回传 | 脱敏；禁止复述敏感字段 |
| F05 越权查询 | 查他人订单 | adversarial | 鉴权、工具 ACL | 工具层拒绝；提示对齐 |
| F06 该拒不拒 | 写诗/荐股/医疗 | refuse | 意图分类过宽 | 域外拒答模板 |
| F07 该问不问 | 无订单号仍编物流 | edge | 槽位检查 | 强制澄清模板 |
| F08 冗长跑题 | 超长、营销堆砌 | 长度卫生 | 解码/提示 | 字数与结构约束 |
| F09 语气对抗 | 辱骂式拒绝 | 人工观感 | 拒答话术 | 标准礼貌拒答 |
| F10 不稳定 | 同用例时过时不过 | 抖动 | 温度、采样 | temperature→0；多跑取稳 |
