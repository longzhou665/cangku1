# D08 客户交接说明（内部知识助手）

## 你们得到了什么

1. 可回归的知识助手质检体系（用例 + 断言 + CI）  
2. **知策评测控制台**：可视化维护用例、跑评测、看报告、改提示词  
3. 操作说明：`docs/ops-guide.md`（控制台内同步）

## 日常入口（推荐）

```bash
cd templates/chat-ai-eval-kit
npm install
npm run console
# 打开 http://127.0.0.1:8787
```

| 场景 | 在控制台 |
|------|----------|
| 看健康度 | 概览 |
| 加真实坏 case | 用例 |
| 改提示词后验证 | 配置 → 评测·冒烟 |
| 出基线 | 评测·全量 → 报告 |
| 新人培训 | 操作说明 |

## 命令行备选

`npm run smoke` / `npm run eval:ci` / `npm run report`

## 责任边界

| 甲方 | 乙方（若买维护） |
|------|------------------|
| 制度条文正确性、知识库更新 | 用例结构、门禁、控制台 |
| 是否放量 | 基线解读与归因建议 |
| API 权限与费用 | 月度回归与报告（月包） |
